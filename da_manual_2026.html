ゴール：

第1章：【必修】Excelで「ピーク」を知る

まずは全員が使えるExcelを使って、最も重要な情報である「魔の時間帯（いつ忙しいか）」を特定します。
2025年のデータを使って、実際に手を動かしてみましょう。

STEP 1：正しいデータの読み込み方（文字化け防止）

⚠️ 注意：CSVファイルをダブルクリックしないでください！
直接開くと文字化けしたり、「090」が「90」になったりとデータが壊れる原因になります。
必ず以下の手順で「インポート」してください。
正しい手順：
1. Excelを「空白のブック」で新規作成して開く
2. [データ] タブをクリック
3. [テキストまたはCSVから] をクリックして all_log.csv を選択
4. プレビュー画面が出たら、そのまま [読み込み] をクリック
これで文字化けのない、きれいなテーブルとして取り込まれます。

STEP 2：ピボットテーブルで集計

取り込んだ表の中にカーソルを置き、[挿入] → [ピボットテーブル] をクリックします。
わざわざ関数で「何時」を取り出さなくても、Excelが自動で判別してくれます。

設定項目 操作
行 「時刻」をドラッグ＆ドロップ
※自動的に「時」「分」などにグループ化されます。
「時」だけを残し、他（分など）は枠外へ捨ててください。
値 「合計金額」（集計方法：合計）

STEP 3：ヒートマップで可視化

数字が並んだだけでは直感的にわかりません。「条件付き書式」を使って色をつけます。
集計された数字の範囲を選択し、[ホーム] → [条件付き書式] → [カラースケール] を選んでください。

2025年の分析結果：
実際に分析すると、17時台が真っ赤（売上最大）になるはずです。
逆に14時〜15時は色が薄くなります。
この結果から「休憩は15時に回し、17時は全員体制にする」という戦略が生まれます。

第2章：【発展】Pythonで「相関」を読む

ここからは上級編です。Excelでは難しい「商品Aと商品Bの同時購入（セット買い）」を分析します。
2025年の大学祭では、「どのポストカードをセット販売にするか？」をこの分析で決定しました。

⚠️ 環境について
Pythonの導入方法（Anaconda, VS Code等）や実行方法は、Webで「Python 環境構築」などを検索してください。
本マニュアルでは、環境構築済みのPCで実行するコードを紹介します。

コード例：一緒に買われた商品を見つける

以下のコードは、all_log.csv を読み込み、相関係数（一緒に買われる確率）が高い組み合わせを抽出します。

import pandas as pd

# 1. 2025年大学祭データの読み込み
df = pd.read_csv('all_log.csv')

# 2. 商品の列だけを範囲指定（ワッフル〜写真撮影まで）
# ※実際のCSVの列番号に合わせて調整してください
item_columns = df.columns[7:33] 

# 3. 相関係数の算出（これが魔法のコマンドです）
correlation_matrix = df[item_columns].corr()

# 4. 強い相関があるペアをランキング表示
print("--- 同時購入されやすいペア BEST 5 ---")
corr_pairs = correlation_matrix.unstack().sort_values(ascending=False)
# 自分自身(1.0)を除外
corr_pairs = corr_pairs[corr_pairs < 1.0]
print(corr_pairs.head(10))

分析結果の見方（相関係数の目安）

計算された数字（相関係数）をどう判断すればいいか、以下の表を参考にしてください。

相関係数 判定 推奨アクション
0.7 〜 1.0 非常に強い 袋詰めして「セット販売」にする
0.4 〜 0.7 やや強い 近くに並べて「ついで買い」を狙う
0.2 〜 0.4 弱い 特に関係なし
0.0 〜 0.2 なし 無視してOK

2025年の分析結果

このコードを実行すると、以下の結果が得られました。

  • ポスカ (ノンディレクショナルレーザー) と ポスカ (サテライトイリュージョン)
    → 相関係数：0.86 (極めて高い)
インサイト：
この2枚は「ほぼ確実にセットで買われている」ことがわかります。
ここから「最初から袋詰めした『弾幕セット』を作り、レジの時間を短縮する」というアイデアにつなげることができます。

第3章：【概念】SQLで「太客」を探す

データが100万行を超えたり、データベースで管理するようになった場合は「SQL」を使います。
ここでは「2025年のデータから、客単価の高いお客様（太客）を抽出する」思考法を紹介します。

※実行には「DB Browser for SQLite」などのツールが必要です。導入はWeb検索してください。

抽出クエリ：高額購入者のリスト化

SELECT 
    時刻, 
    客層, 
    合計金額 
FROM 
    all_log 
WHERE 
    合計金額 >= 1500 
ORDER BY 
    合計金額 DESC;

集計クエリ：Excelのピボットテーブルと同じことをする

SQLの凄いところは、集計も一瞬で書けるところです。
以下は「客層ごとに、いくら売上があったか？」を集計する魔法のコードです。 

SELECT 
    客層, 
    SUM(合計金額) AS 売上合計
FROM 
    all_log 
GROUP BY 
    客層
ORDER BY 
    売上合計 DESC;
解説：
GROUP BY（グループバイ）という命令を使うと、「客層」という項目ごとにデータをまとめて計算してくれます。
Excelでマウスを動かして設定していた作業が、この数行のコードだけで完結します。

第4章：分析からアクションへ

最後に、最も大切なことを伝えます。
きれいなグラフを作ることや、難しいコードを書くことが目的ではありません。

分析の鉄則：
分析結果が出たら、必ず「だから、次はこうする」というアクションを決めてください。
  • 「17時が忙しい」→ だから「シフトを厚くする」
  • 「この2つはセットで売れる」→ だから「セット割引を作る」

2025年のデータ（all_log.csv）は、先輩たちが残してくれた「宝の地図」です。
この地図を読み解き、さらに素晴らしい結果を出してください。
