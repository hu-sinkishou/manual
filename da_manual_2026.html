第1章：【必修】Excelで「ピーク」を知る

まずは全員が使えるExcelで、「魔の時間帯（最も忙しい時間）」を特定します。

STEP 1: データの前処理（時刻の抽出）

CSVをExcelで開いただけでは、「2025-11-01 10:41:22」という細かい時刻データしかありません。
これを集計するために、隣の列に「何時台か」を取り出します。

  1. J列（空いている列）の先頭に「時間」と入力。
  2. その下のセル（J2）に =HOUR(B2) と入力。
    ※B列が時刻の場合。これで「10」や「17」という数字だけが取り出せます。
  3. 下までオートフィル（コピー）します。

STEP 2: ピボットテーブルでクロス集計

「時間」と「売上金額」の関係を表にします。

  1. 表全体を選択し、「挿入」タブ → 「ピボットテーブル」をクリック。
  2. 行：「時間」
    値：「合計金額」（合計）

STEP 3: ヒートマップで可視化

数字だけでは直感的に分かりにくいため、色をつけます。

  1. 集計された数値の範囲を選択。
  2. 「ホーム」タブ → 「条件付き書式」 → 「カラースケール」 → 「赤・白・青」などを選択。
💡 分析結果（インサイト） 実際に all_log.csv を分析すると、以下の事実が判明しました。
  • 17時台が最大のピーク（売上が急増）。
  • 逆に14時〜15時は中だるみする傾向がある。
➡ アクション： 「17時に人員を最大化し、休憩は15時に回す」

第2章：【概念】SQLで「太客」を探す

データが100万行を超えたり、より複雑な条件でデータを抽出したい場合は、データベース言語「SQL」の出番です。
ここでは、「どんな思考でデータを抜くか」のイメージを掴んでください。

※SQLの実行環境構築については、Webで「SQLite 導入」「DB Browser for SQLite」などを検索してください。

例：客単価が高い「優良顧客」リストを作る

「合計金額が1,500円以上の取引」だけを抜き出し、支払額の大きい順に並べる命令文です。

SELECT 
    決済番号, 
    時刻, 
    客層, 
    合計金額 
FROM 
    all_log 
WHERE 
    合計金額 >= 1500 
ORDER BY 
    合計金額 DESC;

解説：

  • SELECT：欲しい列を選ぶ（「誰が」「いくら払ったか」）
  • FROM：データ元を選ぶ（all_logテーブル）
  • WHERE：条件で絞り込む（1500円以上）
  • ORDER BY：並べ替える（高い順＝DESC）

第3章：【発展】Pythonで「相関」を読む

Excelでは難しい「商品Aと商品Bの同時購入（相関関係）」を分析します。
「ポスカ（ポストカード）」の種類が多すぎて「どれとどれをセットにすべきか」悩んだ時、Pythonなら一瞬で答えを出せます。

※Python環境（AnacondaやVS Codeなど）の構築は、「Python インストール」で検索してください。
以下のコードは、必要なライブラリ（pandas, matplotlib等）がインストール済みであることを前提としています。

実装コード：商品間の相関行列ヒートマップ

このスクリプトを実行すると、全部の商品ペアについて「一緒に買われる確率」を計算します。

import pandas as pd

# 1. データの読み込み
# ※Shift-JIS等の文字コードエラーが出る場合は encoding='cp932' を指定
df = pd.read_csv('all_log.csv')

# 2. 分析対象のカラム（商品列）を指定
# ワッフルからポスカ、写真撮影までの列名を取得
item_columns = df.columns[7:33] 

# 3. 相関係数の算出
# corr()関数一発で、全ての組み合わせの相関(-1.0 〜 1.0)を計算します
correlation_matrix = df[item_columns].corr()

# 4. 強い相関（0.4以上）があるペアだけを表示
# 重複を除いてリストアップする処理
print("--- 同時購入されやすい商品ペア BEST 5 ---")
corr_pairs = correlation_matrix.unstack().sort_values(ascending=False)
# 自分自身との相関(1.0)を除外
corr_pairs = corr_pairs[corr_pairs < 1.0]
print(corr_pairs.head(10))
