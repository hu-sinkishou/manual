Excel操作マニュアル

基礎から始める、間違いのないデータ管理術

「Excel（エクセル）は、あなたの最強のパートナーです」
このマニュアルでは、サークルの会計業務に必要なExcel操作に絞って解説します。
難しい関数を覚える必要はありません。基本の型とルールさえ守れば、計算ミスゼロの運営が可能です。

第1章：データの場所（PCとTeamsの関係）

作業は自分の使い慣れたパソコンで行い、完成した大切なデータはTeamsに預ける。これが基本の流れです。

1. 作業場所と保管場所

  • 自分のPC（作業机）：
    ファイルを作成したり、修正したりするのは、個人のパソコン上で行います。動作も早く、集中して作業できます。
  • Teams（金庫）：
    作業が終わったファイル、あるいはみんなに共有したいファイルはTeamsにアップロードします。ここは「保存・共有専用」です。
注意：
PCで作業している間は、データはまだあなたの手元にしかありません。
こまめに「上書き保存 (Ctrl + S)」をする癖をつけましょう。

第2章：表とシートの作り方

Excelは真っ白なキャンバスです。いきなり数字を入れるのではなく、まずは「入れ物」を作りましょう。

1. 「シート」を使い分ける（情報の整理）

画面の左下にあるタブを「シート」と呼びます。
1つのファイルの中に、ルーズリーフのように何ページでも追加できます。

  • 日付ごと： 「4月」「5月」「6月」…と月ごとにシートを分ける。
  • 項目ごと： 「レシート集計」「部費管理」「合宿費」…と目的別に分ける。

全部を1枚にまとめようとせず、シートを増やして整理すると、後で見返す時にとても楽になります。

2. ヘッダーを作る（表の看板）

表の一番上の行（1行目）には、必ず「そこに何が入るか」のタイトル（ヘッダー）を書きましょう。
これがないと、後で見た時に何の数字かわからなくなります。

見やすくするコツ：
ヘッダーの行を選択して、文字を「太字」にしたり、セルの色を薄いグレーにしたりすると、データ部分との区別がついてグッと見やすくなります。

3. 数字の「迷子」を防ぐ（ラベルの徹底）

表の外などで計算する際、数字だけをポツンと置いてはいけません。
「その数字が何なのか」を示す言葉（ラベル）とセットにするのが、見やすいExcelの一貫したルールです。

❌ NG（数字だけ） ⭕ OK（ラベルあり）
5,000
（これ何のお金？）
合　計
5,000
（一目で分かる！）

このように、値を入力するセルの左側（または上）には、必ず「合計」「残金」「立替分」といった見出しを付けてください。
誰が見ても（未来の自分が見ても）意味が分かるようにしましょう。

4. 格子（枠線）をつける

数字やラベルを入れたら、その範囲を選択して「田」のようなマーク（格子）をクリックして線を引きます。
印刷した時や、画面で見る時の見やすさが段違いです。

第3章：入力の鉄則

Excelは「見せる資料」であると同時に「計算機」でもあります。
正しく計算させるために、1つだけ絶対に守るルールがあります。

これだけはNG：「円」と入力しない！

❌ 悪い例：1000円
⭕ 良い例：1000

「円」という文字が入ると、Excelはそれを「数字」ではなく「文字」として扱ってしまい、計算ができなくなります。
「¥」マークや「円」を表示させたい場合は、数字を入力した後、メニューにある表示形式の設定（¥マークなど）で見た目だけを変えてください。

セルの結合について

見出しを整えるためや、レイアウトを見やすくするために「セルの結合」を使うのはOKです。
見る人が分かりやすい資料作りを心がけましょう。

第4章：計算の基本（四則演算と参照）

電卓を叩いて、その結果をExcelに入力するのはやめましょう。
Excel上で計算式を作れば、元になる数字が変わった時に、答えも自動で修正してくれます。

1. 四則演算（足す・引く・掛ける・割る）

計算式を入れる時は、必ず半角の = （イコール）から始めます。
算数とは使う記号が少し違うので注意してください。

計算 記号 入力例
足し算 + =100+50
引き算 - =100-30
掛け算 * (アスタリスク) =100*1.1 (消費税など)
割り算 / (スラッシュ) =1000/4 (割り勘など)

2. 「セル参照」の魔法

直接「=100+200」と入力するのではなく、「A1のセルの数字 と B1のセルの数字 を足す」という指定の仕方をします。
これを「セル参照」と呼びます。

やり方：
1. = を入力する
2. 足したいセル（例：A1）をマウスでクリック
3. + を入力する
4. もうひとつのセル（例：B1）をクリック
5. Enter を押す → 完了！

3. まとめて計算（範囲指定・SUM関数）

レシートが10枚ある時に、全部を「+」でつなぐのは大変です。
そういう時は、範囲を指定して合計を出します。ここでも「ラベル」を忘れずに。

  • SUM関数： =SUM( ) と入力し、カッコの中に合計したい範囲をマウスでドラッグして選びます。（例：=SUM(D2:D15)）
  • 範囲の意味： 「D2:D15」は、「D2からD15までの全部」という意味です。
