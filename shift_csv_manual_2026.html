DATA SOURCE

members.csv 編集マニュアル

シフト自動作成の元データとなるスタッフ情報ファイル（members.csv）の仕様と、VSCode等を用いた入力・編集時の注意点を解説します。

OVERVIEW

1. 概要と基本ルール

役割: スタッフの名前、担当可能な役職、責任者の可否、各時間帯のシフト希望を集約するファイルです。

ファイル名と保存場所: 必ず members.csv という名前で、config フォルダ内に配置してください。

エンコーディング: UTF-8形式で保存してください。

基本ツール: 本手順は Visual Studio Code (VSCode) 等のテキストエディタでの編集を前提としています。

HEADERS

2. CSVの列（ヘッダー）定義

CSVの1行目（ヘッダー行）は、以下の必須項目を含んでいる必要があります。
※システムは名前で列を判定するため、必須項目が存在していれば「メールアドレス」などの不要な列が含まれていても無視され正常に動作します。

必須となる列

  • お名前: スタッフの氏名
  • 役職: 担当可能な役職
  • 責任者: 責任者として担当可能な役職（該当なしの場合は空白）
  • 時間枠: config.json の time_slots の label（例：10:00）と完全に一致する列名
  • その他: （任意）備考やコメント。出力Excelに転記されます。

VSCodeでの見え方の例

カンマ（,）で区切られた以下のような1行になります。

お名前,メールアドレス,役職,責任者,10:00,11:00,その他
RULES

3. 各項目の入力規則

お名前

空白不可です。必ず入力してください。

役職・責任者

config.json の roles で定義した "name"（例：「レジ」「宣伝」）と完全に一致する文字を入力してください。

  • 複数入力する場合: 複数の役職を担当できる場合は、必ず半角カンマ（,）のみで区切ってください。
  • 【正しい例】 "レジ,宣伝" （※CSVの列としてズレないよう " で囲む必要があります）
  • 【誤った例】 レジ、宣伝 （※読点はエラーになります）

時間帯（シフト希望）

config.json の keywords で定義された文字列のみ入力可能です。

  • 可能: 〇, OK, 可能 など
  • 緊急: △, 緊急, いざとなれば など
  • 不可: ×, 不可, -, 空白 など

📝 「その他」列への特殊記号の入力について

文章内に半角カンマ（,）を使うと列が区切られたと誤認されデータがズレます。文章内にカンマを含めたい場合は、文章全体を半角のダブルクォーテーション（"）で囲ってください。

  • 【正しい例】 "15時以降ならレジも可能です, よろしくお願いします"
  • 【誤った例】 15時以降ならレジも可能です, よろしくお願いします
WORKAROUND

4. Microsoft Forms の回答を利用する場合の注意点

Forms の出力CSVを利用する場合、複数選択項目の区切り文字が セミコロン（;） で出力されます。システムはカンマ区切りを要求しますが、単純な一括置換では列がズレるため、以下の手作業による修正を行ってください。

  • 【修正前（Forms出力）】 お名前,レジ;原作コーナー,10:00
  • 【修正後（正しい形式）】 お名前,"レジ,原作コーナー",10:00

修正手順（手作業）

  1. members.csv をVSCodeで開きます。
  2. 検索パネルを開き（ショートカット：Ctrl + F）、; （半角セミコロン）を検索します。
  3. セミコロンが使われている箇所を見つけたら、その ; を , （半角カンマ）に書き換えます。
  4. さらに、その役職のまとまり全体を " （半角ダブルクォーテーション）で囲みます。
  5. すべての該当箇所を修正するまで繰り返し、完了したら保存します。
TROUBLESHOOTING

5. よくあるエラーとチェックポイント

不要な空白の混入

レジ のように、役職名の前後にスペース（全角・半角）が入っているとエラーになります。

ヘッダー名の不一致

CSVの時間列名（例：10:00）と config.json の label が一言一句一致しているか確認してください。

ダブルクォーテーションの閉じ忘れ

" で囲む場合は、必ず文の最初と最後に配置してください。
